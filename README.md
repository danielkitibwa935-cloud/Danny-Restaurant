Danny Restaurant

An online restaurant ordering and management system.

Project Overview

Danny Restaurant provides customers with an easy way to browse meals, place orders and track their orders.

It also provides a private administration dashboard for the restaurant owner to manage products, categories, orders and business reports.

Project Structure

- "customer/" — Public customer website
- "admin/" — Private administration dashboard
- "functions/" — Backend functions
- "firebase.json" — Firebase Hosting configuration
- ".gitignore" — Files excluded from Git

Technologies

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Functions

Currency

Ugandan Shillings (UGX).

Development Status

Project foundation and architecture are being prepared. Features will be implemented stage by stage.

Access

The administration dashboard is initially intended for the restaurant owner only.
